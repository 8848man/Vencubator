# ADR-005 — 기존 기록 위에 재개 가능한 작업 뷰

2026-09-27 · AUTH-017 / SPEC-013 r0.1

결정: Task는 기존 학습/산출물/실행/근거의 projection + 사용자 TaskMeta. 학습과 태스크에 각각 완료를 저장하지 않는다. 기존 프로젝트 데이터와 보상 유지, taskId별 현장 초안과 route.fieldTaskId로 병행 작업을 구분한다.
대안: 새 workflow engine과 별도 이벤트 저장소는 현재 규모에서 중복 상태/이관 위험이 커 제외. MVP에서는 이 계약을 서버 원자적 트랜잭션으로 이식한다.
제약: 프로토타입 localStorage는 기기 간 동기화 없음. 기존 다음 행동 단일 필드는 레거시 평가 호환용이며 새 작업 목록의 권위가 아님. 선택한 현장 과제의 판단 기준을 연결하고 다른 과제를 자동 완료하지 않는다.
