# P08-W03 — 가치 카드·의견 보내기 UI

AUTH-024 · S1/P08 · SPEC-015 r0.3 · 브랜치 `w/P08-W03-feedback-ui` (기반 `w/P08-W02-feedback-schedule`, 미병합 쌓기).
범위: W02 로직을 앱에 연결. 4개 도착 화면의 비모달 가치 카드, 의견 보내기 전용 페이지와 진입점, 브라우저 검증. 응답은 로컬 outbox에만 쌓임(전송·GA는 W04).

## 규모 판단
명세 보완 + 새 UI 모듈·CSS + app 연결 + 브라우저 QA 스크립트 + VAL + CP·PR, 변경 파일 8개 이상 → 계획 선행 대상.

## 설계 메모
- 가치 순간 감지: render 뒤 `occurrences()`를 이전 값과 비교해 늘어난 카테고리가 그 카테고리의 도착 화면(idea: born·dashboard, learning: session 완료, evidence: dashboard, decision: journal)에 있을 때만 `duePrompt` 판단. 도메인·핸들러 수정 없음.
- 보상 다이얼로그가 열려 있으면 닫힌 뒤 카드를 붙이고 그때 `markShown`.
- 카드 위치: 학습 완료는 실행 안내 앞, born은 버튼 줄 앞, 그 외는 ‘지금 할 일’ 카드 또는 페이지 제목 뒤.
- 다시 그리기: 같은 화면이면 매 render 뒤 같은 카드(선택한 점수·칩·의견 유지)를 다시 붙임. 화면을 떠나면 점수 있으면 answered, 없으면 unanswered로 확정. pagehide 때도 확정·저장.
- 의견 보내기 진입: 데스크톱 사이드바 하단, 모든 화면 하단 안내줄(모바일 포함), 설정 화면. 전용 `feedback` 뷰, 들어온 화면으로 복귀.
