# L08-W04 — 레퍼런스 기반 첫 흐름과 아이디어 없는 앱 진입

S1/L08 · AUTH-033 · SPEC-019 r0.5 예정 · ADR-007 준수

목적: `/v3.3/`의 네 화면 압축형 체험을 54장 레퍼런스의 화면 리듬·시각 언어를 참고한 다화면 첫 흐름으로 바꾸고, 구체적 아이디어가 없는 사용자도 요약에서 앱으로 들어가게 한다. 실제 인증·AI 추천·서버 저장·54장 전체 필수 노출은 범위 밖이다. 기존 사용자 수정 `site/audience/render.mjs` 및 미추적 자료는 보존한다.

## 수용 기준

검증 방법 변경: 2026-10-14, 앞 작업에서 4180 IAB 접근이 브라우저 정책으로 거부되어 동일 결과를 우회하는 브라우저 수동 검증은 하지 않는다. 자동 검사·정적 빌드와 사용자 체험 경로를 기록한다.

- 질문 한 화면·설명 화면·선택 요약을 통해 사용자가 답의 용도를 이해한다. 응답은 평가·검증된 AI 추천으로 표현하지 않는다.
- 54장 구조의 가치 약속→맞춤 질문→요약→실제 앱 행동을 이어가되, 출시 체험에 54장을 모두 강제하지 않는다.
- 구체적 아이디어 문장은 선택이다. 비어 있거나 아직 아이디어가 없다고 답한 사용자는 요약에서 `/app/`으로 진입하고 프로젝트 입력 코치마크에 갇히지 않는다.
- 아이디어가 있는 사용자는 기존 실제 앱 프로젝트 코치마크로 갈 수 있다. 기존 프로젝트·초안은 덮어쓰지 않는다.
- 새로고침·뒤로가기·재방문·저장 차단 상황을 처리하고 모바일 폭에서 조작 가능하다.
