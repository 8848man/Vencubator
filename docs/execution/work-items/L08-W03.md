# L08-W03 — 저장형 첫 흐름과 실제 앱 프로젝트 코치마크

S1/L08 · AUTH-032 · SPEC-019 r0.4 예정 · ADR-007 준수

목적: `/v3.3/`을 첫 사용 정보 수집·튜토리얼 체험 경로로 바꾸고, 마지막 프로젝트 실습을 실제 `/app/` 화면의 단일 활성 조작 코치마크로 연결한다. 브라우저 로컬 저장 기반 S1 체험이며 실제 소셜·이메일 인증, 서버 계정 저장, 네이티브 저장소 연동은 범위 밖이다.

규모 판단: 명세→사이트·앱 구현→브라우저 검증→PR이며 변경 파일이 4개를 넘는다. 기존 사용자 수정 `site/audience/render.mjs`와 미추적 자료는 보존한다.

## 수용 기준

- `/v3.3/`에서 벤큐베이터 맞춤 질문과 1~4구간 튜토리얼을 조작하고 입력을 로컬에 저장·복원한다.
- 완료 표시는 인증 상태와 분리하고, 앱 데이터가 있는 브라우저의 기존 기록을 덮어쓰지 않는다.
- 5구간은 실제 앱 DOM을 어둡게 덮고 한 대상만 강조한다. 다른 컨트롤의 포인터·키보드 조작을 막고 도움말·진행 상태를 보여준다.
- 첫 프로젝트 생성 후 코치마크가 종료되고 일반 앱 조작으로 돌아간다.
- 실제 인증 및 계정 동기화로 오인하지 않도록 체험 경계를 표시한다.
