# L08-W06 — 첫 안내 메인 라우트와 랜딩 분리

S1/L08 · AUTH-035 (2026-10-14 사용자 현재 요청) · SPEC-019 r0.7 예정. 기반: L08-W05 브랜치·PR #20.

목적: 현재 `/v3.3/`의 15화면 첫 안내를 사이트 `/`에서 직접 제공하고, 기존 v3.1 독자 선택 랜딩을 `/landing/`에서 유지한다. `/app/` 새 데모 사용자의 첫 실행도 메인 안내로 연결한다. `/v3.3/`은 기존 링크 호환 경로로 남긴다. 사용자 추가 요청에 따라 54장 레퍼런스는 별도 HTML 경로로 유지하고 튜토리얼 하단에서 해당 진입 링크를 제거한다. 기존 사용자 자료와 별도 미커밋 변경을 보존한다.

## 수용 기준

- `/`는 화면 폭과 관계없이 첫 안내 HTML·스크립트를 제공하고 모바일 자동 앱 이동을 실행하지 않는다.
- `/landing/`은 기존 독자 선택 랜딩을 제공하며 현재 랜딩의 주요 인터랙션과 앱 진입 링크가 동작한다. `/landing` 요청은 로컬 서버에서 `/landing/`으로 정규화한다.
- 새 데모 `/app/` 첫 실행은 `/`로 보내며 완료·기존 기록·명시적 인계의 기존 보호 조건을 유지한다. `/v3.3/`과 `/v3.3/reference/`는 계속 열린다.
- canonical·sitemap·사이트 안내·회귀 검사를 새 공개 경로에 맞춘다. 4180 수동 브라우저 확인 및 운영 배포는 별도 확인 대상으로 남긴다.
