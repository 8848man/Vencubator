# L08-W01 — 모바일 직접 진입과 첫 사용 UX

S1/L08 · AUTH-030 (2026-10-13 사용자 현재 요청 및 정정) · SPEC-019 r0.2

목적: 모바일 루트 방문을 앱으로 연결하고, 처음 앱을 실행하는 사람에게 짧은 설명과 아이디어 상태 질문을 거쳐 기존 프로젝트 시작으로 이어지는 흐름을 제공한다. 독립 랜딩 v3.3은 이 흐름을 설명하고 직접 체험할 수 있게 한다. 기존 사용자 기록, 데스크톱 독자별 랜딩, 운영 배포는 보존한다.

규모 판단: 새 화면 흐름·앱 상태·사이트 라우팅·별도 랜딩·검증·CP가 이어지는 다중 파일 작업이다. 파일 삭제가 차단된 현 환경에서 `gitflow start`는 `.git` 쓰기 불가로 실패했다. 소스 작업 후 commit/finish는 handoff로 남긴다.

5번 완료 기록: 기존 사용자 수정·미추적 파일 때문에 `gitflow finish --pr`의 dirty guard가 중단했다. 이후 사용자가 `8848man/Vencubator`가 본인 저장소이며 L08 커밋의 push·PR을 승인했다. 해당 브랜치의 커밋만 push하고 PR #16을 생성했다. 기존 사용자 수정·미추적 파일은 PR에 포함하지 않았다. PR 생성 직후 사용자가 `/v3.3/`의 역할을 정정했다. 6~9번은 그 정정 범위이며 PR을 갱신한다.

### 범위 경계

첫 사용 답변은 로컬 브라우저 저장이며 개인화의 입력일 뿐 검증된 사업 정보가 아니다. 이름·아이디어 외 추가 프로필은 요구하지 않는다. 추천 문구는 사용자가 수정할 수 있다. 기존 프로젝트와 이전 앱 상태를 초기화하지 않는다.
