# L08-W02 — 최초 흐름 완료 표시와 비로그인 재진입 UX 설계

S1/L08 · AUTH-031 (2026-10-13 사용자 현재 요청) · SPEC-019 r0.3 예정 · ADR-007 예정

목적: 첫 진입 흐름의 재표시 여부와 인증 상태를 분리하고, 최초 흐름을 완료했으나 로그인하지 않은 사용자의 별도 로그인 경로를 설계한다. 이 W는 명세·상태 계약·화면 흐름 설계까지만 수행한다. 실제 카카오/구글/이메일 인증, 서버 세션, 모바일 네이티브 저장 구현은 하지 않는다.

규모 판단: 제품 Spec, 저장·인증 기술 결정 ADR, 상태별 화면 경로, 검증 기록, CP·PR로 이어지는 다중 파일 설계 작업이다. 선행 L08-W01 PR 위에 쌓는 새 브랜치로 시작했다. 기존 사용자 수정과 미추적 자료를 보존한다.

## 설계 수용 기준

- `first flow 완료 여부`와 `로그인 여부`를 별도 상태로 표현하고 네 조합의 첫 화면을 결정한다.
- 완료 표시가 있어도 비로그인 상태이면 독립 로그인 화면으로 진입하며, 완료 표시만으로 앱 계정 데이터에 접근하지 않는다.
- 로그인 취소·실패·만료·저장 삭제·다른 계정 로그인·기존 사용자 재방문 경로를 정의한다.
- 브라우저 localStorage와 모바일 앱 저장의 의미를 구분하고, 인증 토큰의 저장 위치와 서버 권위를 ADR로 분리한다.
- 프로토타입·MVP 구현 경계를 명확히 적는다. 이번 W의 완료는 설계 완료이며 기능 구현 완료가 아니다.
