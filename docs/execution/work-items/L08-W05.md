## 수용 기준

- 새 데모 사용자는 `/app/` 첫 방문에서 기존 첫 흐름을 열고, 완료 후 실제 프로젝트 화면으로 간다. 프로젝트 기록이 있는 재방문자는 기록을 그대로 연다.
- 완료 표시는 UX 선호이며 로그인 증빙으로 쓰지 않는다. 저장 차단과 구버전 URL에서 무한 이동하지 않는다.
- 기존 앱 SVG 캐릭터와 로고를 사용한다. 캐릭터는 화면마다 고정 공간 안에서 조금씩 커지고 반짝이며 OS 모션 감소를 존중한다.
- SPEC-008의 260ms 진입·50ms 그룹 순차·최대 200ms 규칙을 적용하고 기존 구현·명세 위치를 연결한다.
- 4180 수동 브라우저 검증은 기존 보안 정책에 따른 접근 제한을 우회하지 않고 미실행으로 기록한다.
