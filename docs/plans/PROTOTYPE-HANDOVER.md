## 현재 경계

- Screen 01~13의 대표 흐름이 로컬에서 작동한다. 브라우저 주소/프로필별 저장이며 서버/계정 간 공유가 없다.
- 고객·제품의 첫 가설은 인터뷰에서, 다른 영역의 확인 대상 가설은 관찰 폼에서 명시한다. 전략은 별도 Decision이 있어야 성장한다.
- 가설별 관찰을 구분하며 프로젝트 scope가 바뀌면 현재 단계/근거 상태를 초기화하고 과거 최고는 보존한다. 단순한 출처명 차이가 실제 독립성을 입증하는 것은 아니다.
- 7개 축을 보여주지만 28개 전체 적격 산출물 검수, 전략 반복실험 종합, 90일 재확인, 7일 숙달 재검사, 근거 철회/정정/서버 동시성은 MVP 작업으로 남는다.
- 학습 채점은 고정 정답+이유 선택이다. 전문가 능력 평가나 자유서술 AI 채점이 아니다.
- 저장 실패 때 현재 폼의 입력은 유지된다. 저장 실패 중 화면을 떠나거나 새로고침하면 미저장 입력은 복구할 수 없다. 실제 오프라인 큐·다중 탭 충돌은 미구현이다.
- 모든 관찰 데이터는 가상 예시다. 운영 환경으로 import하지 않는다.
