## 해석과 가정

- A01: SDD는 Specification Driven Development로 해석한다.
- A02: 첫 고객은 아이디어는 있지만 고객 검증 경험이 적은 한국어 사용 1인 빌더다. 연구 대상 가설이며 확정 시장이 아니다.
- A03: 1인 또는 소규모 팀의 12주 실행을 전제로 Web 베타와 Android 테스트 배포를 목표로 한다. 스토어 공개 승인은 외부 변수이므로 완료를 보장하지 않는다.
- A04: 코드 대신 실제 폴더에 연결된 Markdown 명세와 상태 파일을 만드는 것이 이번 요청의 SDD 완성 범위다.
- A05: 제안은 `Proposed/Review-ready`로 둔다. 사용자 수락을 허위 기록하지 않는다.
- A06: 후속 요청으로 3단계 순서는 확정되었다. 상세 Phase/일정·기술·기능 구현 승인은 별개다. 기존 12주는 프로토타입 2주+MVP 10주로 재구성하는 안이며 고도화 기간은 이후 추정한다.
