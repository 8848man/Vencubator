# 프로토타입 사용자 검증 진행표

P04-W02 · 준비 자료 · 실제 수행 0명 · 결과 미확정

## 진행 방법

참가자에게 가상 데이터 체험이며 실제 사업 평가가 아님을 설명하고 기록 동의를 받는다. 실명·연락처·고객 개인정보 대신 P01 등의 익명 ID를 쓴다. 관찰자는 정답을 알려주지 않고 도움을 준 지점을 별도 기록한다. 외부 연락·모집·녹화는 아직 수행하지 않았다.

사용성 과제는 창업 초보 5명이 각자 수행한다. 약 20~30분 동안 아래 순서로 관찰한다.

1. 한 문장으로 프로젝트를 만들고 설명 없이 첫 학습을 시작한다.
2. 개념→문제→다른 상황의 응용을 진행한다. 오답 피드백을 보고 다른 문제를 푼다.
3. 자기 프로젝트의 준비물을 작성하다 새로고침하고 복구하여 확정한다.
4. 학습 완료와 실제 실행 완료의 차이를 자기 말로 설명한다.
5. 실행 과제를 선택하고 대기 중 다음 학습을 진행한다.
6. 가상 실행 결과를 남기고 다음 추천과 프로젝트 상세를 확인한다.

## G-P 판단

제안 기준: 기본 과제 5명 중 4명 수행, 중대한 성공점수 오해 해소, H01/H05 결과 기록. 현재 모집·동의·실행 자료가 없으므로 G-P는 미평가다. 참가자 결과가 제공되거나 실제 연구가 승인되어 수행된 시점에 재개한다.

결과를 익명 요약 파일로 저장하고 VAL-003에 분모·도움 여부·한계·판단을 추가한 뒤 P04-W02를 완료한다. P04-W03에서 실제 이슈 수정과 MVP 진입 여부를 판단한다.
