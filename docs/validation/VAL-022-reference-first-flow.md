# VAL-022 — 레퍼런스형 첫 흐름과 아이디어 없는 진입

2026-10-14 · L08-W04 · AUTH-033 · SPEC-019 r0.5 · 상태: 자동 검사 통과, 4180 브라우저 수동 실습 미실행

## 확인한 동작

- `/v3.3/` 소스는 네 구간, 15개 화면으로 구성된다. 소개→선택 질문→답의 용도 설명→선택 아이디어→요약 순서다. 질문마다 건너뛰기가 가능하고 현재 화면·응답을 로컬 초안에 저장한다. 이전 4화면 초안의 값은 보존하고 위치는 첫 화면으로 옮긴다.
- 아이디어가 없는 요약의 앱 진입은 `/app/?v33Explore=1`로 간다. 앱은 데모 사용자와 프로젝트 목록을 열며 프로젝트를 생성하거나 기존 새 프로젝트 초안을 덮어쓰지 않는다. 코치마크는 비활성이다. 아이디어가 있는 사용자는 명시적 `v33Guide=1` 진입을 선택할 수 있다.
- 완료 표시는 요약에서 앱 진입을 누를 때만 쓴다. 저장이 차단되면 안내를 보이고 일반 `/app/` 경로로 이동한다. 이 경우 진행 복원과 직접 목록 진입은 보장되지 않는다.
