## 변경 요약
- `prototype/task-ui.mjs`: active 카드 상단을 `[상태 뱃지] [5단계 표시] [관련 분야]` 한 행으로 구성. r0.3의 박스형 그래프·단계명·‘완료/현재/예정’ 가시 문구 제거. 각 단계는 시각적으로 숨긴 ‘N단계 단계명 · 완료|현재|미완’ 텍스트, 목록 이름 ‘작업 진행 단계, 5단계 중 N단계 진행 중’, 현재 항목 aria-current="step". 분야명의 가운뎃점 앞뒤 줄바꿈 방지(단어 결합자, 화면 전용). ‘기존 이해를 활용’ 안내는 카드 본문으로 이동.
- `prototype/tasks.css`: 노드 14px(현재 16px)·연결선 6px, 완료=녹색 채움+흰 체크, 현재=녹색 테두리+중심 점+옅은 헤일로, 미완=옅은 테두리 빈 원. 상단 행은 `1fr auto 1fr` 그리드로 표시를 뱃지와 분야 사이 가운데에 두고 최소 8px 간격. 분야 12px 유지·단어 단위 줄바꿈(긴 단어만 내부 줄바꿈). 카드 내부 폭 220px 미만에서만 분야가 다음 줄로 이동(container query). forced-colors 대비 보강.
- `tasks.mjs`·저장 구조·XP·재개·정렬·다이얼로그 스크롤·상세 타임라인 변경 없음.
