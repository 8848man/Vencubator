# VAL-019 — 모바일 진입과 첫 사용 UX

2026-10-13 · L08-W01 · SPEC-019 r0.2 · 로컬 검사

## 사용자 정정 반영 검증

초기 `/v3.3/` 독립 소개 페이지는 사용자 의도와 달랐다. 기존 v3.1 랜딩을 `/v3.3/`에도 조립하고, 600px 이하에서는 `/app/`으로 이동하도록 수정했다. 마이루틴의 54장 화면 전개를 벤큐베이터의 아이디어·학습·고객 확인 문구와 첫 프로젝트 실습으로 번안한 `/v3.3/reference/`를 별도로 추가했다. 원본 스크린샷 파일은 사이트에 복사하지 않았다.

| 확인 | 방법 | 결과 |
|---|---|---|
| 경로 조립 | `node site/scripts/build.mjs` | 성공. `/v3.3/`은 기존 랜딩, `/v3.3/reference/` 별도 조립 |
| 사이트 회귀 | `node --test --test-concurrency=1 site/tests/*.test.mjs` | 31/31 통과 |

| 데스크톱 `/v3.3/` | 로컬 IAB, 제목·기존 첫 화면·앱 CTA URL 확인 | 기존 랜딩 표시, CTA `/app/?from=v31` |

| 레퍼런스 인터랙션 | IAB에서 09번 질문 선택, 35→36번 코치 동작, 아이디어 문장 입력→37번 카드 반영 | 선택 전 다음 비활성, 선택·입력 반영, 코치 동작 통과 |

사이트 테스트를 같은 `dist` 디렉터리를 쓰는 별도 테스트 명령과 연속으로 겹쳐 실행했을 때 ENOENT 3건이 났다. 공유 빌드 산출물의 동시 삭제·재생성이 원인이었고, 단일 프로세스 순차 실행에서는 31/31 통과했다. 실제 모바일 기기, 스크린리더, 사용자 이해도 조사는 여전히 미실행이다. GitHub PR #16은 사용자 정정 후 커밋을 반영하도록 갱신한다.

## 한계

브라우저 확인은 로컬 IAB의 에뮬레이트 뷰포트에서 수행했다. 실제 Android/iOS 기기·스크린리더·스토리지 차단 환경·운영 분석 수신·사용자 연구는 미실행이다. 온보딩 답변은 첫 제안 문구와 아이디어 초안에만 쓰이며 실제 추천 엔진이나 고객 검증으로 취급하지 않는다. 모바일 진입 효과 수치는 아직 없다. 운영 배포·main 병합은 하지 않았다.
