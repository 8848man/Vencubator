## 경계

실제 카카오·Google·이메일 인증, 서버 계정 동기화, 네이티브 모바일 저장소, 운영 배포는 구현·검사하지 않았다. 저장 차단 시 문구와 저장 없는 앱 이동 경로는 코드로 확인했으며, 브라우저 저장 차단 설정을 사용한 수동 재현은 하지 않았다. 완료 표시는 브라우저 UX 선호일 뿐 계정 권한이 아니다. 사용자 실험·전환율 측정도 미실행이다.
