# VAL-020 — 첫 흐름 완료 표시·비로그인 재진입 설계 검토

2026-10-13 · L08-W02 · AUTH-031 · SPEC-019 r0.3 · ADR-007

## 범위와 판정

제품 **설계 문서 검토 통과**. 실제 로그인, 세션, 계정별 완료 기록, 모바일 네이티브 저장 구현은 없으므로 SPEC-019 M07~M11의 **제품 동작 검증은 미실행**이다. 기존 S1 데모의 `demo-user` 자동 생성과 가상 로그인은 그대로다. VAL-019의 구현 검증 판정을 이 설계에 전용하지 않는다.

## 점검 결과

| 검토 항목 | 결과 | 근거 |
|---|---|---|
| 로그인 × 기기 완료 4상태와 인증 확인 중 상태 | 통과 | SPEC-019 `진입 판단 순서` 표. 로그인 계정은 계정 완료 버전을 우선 사용한다. |

## 남은 구현 검증

- M07~M11은 실제 인증·계정 프로필·라우터 구현 후 상태 조합과 접근 권한을 테스트해야 한다.
- 브라우저 저장 차단, 시크릿 모드, 동일 기기 계정 전환, 인증 실패/만료, 사회적 로그인 콜백, 이메일 코드 복구, 익명 초안 확인은 구현 W에서 확인한다.
- 320/390px UI, 키보드, 스크린리더, 네트워크 지연·중복 콜백 검증은 새 화면이 만들어진 후 수행한다.
- 이 W에서 제품 코드, 데이터 마이그레이션, 배포, 외부 인증 설정은 변경하지 않았다.

## 실행 기록

`Test-Path`로 위 여섯 관련 문서 경로를 확인해 모두 존재했다. `git diff --check`는 오류 없이 종료했다. `node scripts/verify-checkpoint.mjs`는 CP-0106 작성 후 SPEC-019가 r0.3으로 변경되었으므로 `Changed since checkpoint: docs/specs/SPEC-019-mobile-entry.md` 한 건을 보고했다. 완료 CP-0107에 새 해시를 게시한 뒤 재실행한다. 이 중간 결과를 제품 테스트 실패로 해석하지 않는다.
