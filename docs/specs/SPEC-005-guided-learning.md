# SPEC-005 — 게임처럼 이어가는 프로젝트 학습

Revision 0.3 · Approved for S1 · AUTH-004 (r0.2 AUTH-016, r0.3 사용자 요청 2026-09-27) · 2026-09-27

사용자 승인: “좋아. 해당 개선점을 기반으로 스펙, 코드 변경 부탁해”. 직전 평가에서 합의한 학습 중심 전환을 구현한다. 실제 AI/인증/푸시·외부 배포 범위는 확대하지 않는다.

## 제품 경험과 명세 우선순위

오늘 한 단계를 플레이하면 내 아이디어에 쓸 수 있는 결과물이 남는다. 색감·새싹 캐릭터는 유지한다. 메뉴 선택은 줄이고 개념 판단과 사업 결정은 사용자에게 남긴다. 이 문서가 SPEC-001/003/004의 기존 대시보드 중심 진입과 6문답 선행 흐름을 대체한다. 성장 수치·근거 적격성의 권위는 SPEC-002를 유지한다.

## 잠긴 학습 안내 (r0.3)

사용자 요청: “‘학습 길’에서 ‘다음에 만나요’ 항목을 클릭했을 때, 그냥 클릭 이벤트만 막는 게 아니라 무엇을 해야 해당 스테이지로 진입할 수 있는지 알려줘야 해. 토스트 팝업으로 해야 되는 것을 알려주고, 해당 스테이지 버튼을 강조”.

- 아직 열리지 않은 학습(‘다음에 만나요’)의 원형 버튼과 옆 글씨는 비활성(`disabled`)으로 두지 않는다. 누를 수 있는 일반 버튼이며(안내라는 동작이 있으므로 `aria-disabled`도 쓰지 않는다), 이름은 “○○ · 아직 열리지 않은 학습, 여는 방법 보기”. 흐린 모양은 유지한다.
- 누르면 학습은 시작되지 않고 저장·이벤트·보상 변화도 없다. 대신
  1. **토스트**: “‘누른 학습’은(는) 아직 열리지 않았어요. 먼저 ○○. 지금 단계를 마치면 다음 학습이 차례로 열려요.” 조사는 이름 끝 글자에 맞춘다. 토스트는 너비 최대 460px, ‘지금 할 일’ 버튼이 있는 화면에서는 그 위에 뜬다. ○○는 지금 단계의 진행 상태에 맞춘 할 일: 시작 전 “‘현재 학습’ 학습을 시작해 주세요”, 개념 “개념부터 이어서 읽어요”, 문제·응용 “문제를 이어서 풀어요”, 적용 “내 프로젝트 준비물을 완성해요”. 토스트는 `role="status"`로 읽힌다.
  2. **지금 단계 강조**: 현재 학습 버튼을 화면 가운데로 스크롤하고 포커스를 옮긴 뒤, 약 2.6초 동안 노란 테두리·살짝 커졌다 작아지는 움직임(3회)과 “여기부터 시작해요” 표시를 보여 준다. 다시 누르면 처음부터 다시 강조한다.
- 모션 감소(기기 설정 또는 앱 설정)에서는 움직임 없이 노란 테두리와 표시만 보여 준다.
- 열리는 순서 규칙(고객 근거가 반박되면 전략 앞당김)은 바꾸지 않는다. 안내는 “지금 단계를 마치면 차례로 열린다”로만 말하고 몇 단계 남았는지 약속하지 않는다.

## 추천·실행·데이터

- 프로토타입 기본 경로: 고객→제품→시장→고객 확보→재무→운영→전략. 고객 근거가 반박되면 아직 안 한 전략 학습을 앞당긴다. 완료한 학습은 복습 가능. 이 결정형 규칙을 실제 AI 개인화라고 표현하지 않는다.
- 새 프로젝트는 Context null 상태로 시작한다. 적용 산출물을 사용자가 확정할 때 대상과 확인 방법을 기존 Context와 병합하되, 기존 확정 고객을 임의 변경하지 않는다. 결과물은 가설/준비물이지 관찰이 아니다.
- 학습 진행은 프로젝트+scopeVersion+concept, 숙달/XP는 사용자+concept 기준이다. 프로젝트 전환 시 산출물/진도는 별도, 기존 지식은 재사용한다.
- 외부 실행은 학습 완료 조건이 아니다. 진행 중 실행 과제는 하나만 유지하며 새 산출물은 보관한다. 다음 학습을 막지 않는다. 교체 시 이전 과제는 보류 이력으로 보존한다.
- 결과 기록은 학습 산출물의 개념/가설과 연결한다. source/date/method/observation/interpretation/limits를 보존한다. 전략 학습의 실행 결과는 Decision으로 이어지며 관찰만으로 전략 보상하지 않는다.
- schemaVersion1에 선택 필드 learningRuns/learningArtifacts/fieldTasks를 추가하며 기존 프로젝트·이벤트·XP·draft를 삭제하지 않는다. 기존 세션은 기존 화면에서 재개할 수 있지만 홈은 새 학습 로드맵으로 진입한다.
- 생명 소모/리더보드/실패 벌점/매일 외부 실행 강제 없음. 기존 모션 감소, 로컬 오류 처리 유지.
