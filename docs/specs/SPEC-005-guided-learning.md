# SPEC-005 — 게임처럼 이어가는 프로젝트 학습

Revision 0.1 · Approved for S1 · AUTH-004 · 2026-09-23

사용자 승인: “좋아. 해당 개선점을 기반으로 스펙, 코드 변경 부탁해”. 직전 평가에서 합의한 학습 중심 전환을 구현한다. 실제 AI/인증/푸시·외부 배포 범위는 확대하지 않는다.

## 제품 경험과 명세 우선순위

오늘 한 단계를 플레이하면 내 아이디어에 쓸 수 있는 결과물이 남는다. 색감·새싹 캐릭터는 유지한다. 메뉴 선택은 줄이고 개념 판단과 사업 결정은 사용자에게 남긴다. 이 문서가 SPEC-001/003/004의 기존 대시보드 중심 진입과 6문답 선행 흐름을 대체한다. 성장 수치·근거 적격성의 권위는 SPEC-002를 유지한다.

## 화면 계약

| 화면 | 목적 / 사용자 행동 | 저장 / 성장 | 다음 |
|---|---|---|---|
| 시작 | 아이디어 한 문장, 이름 선택. 새 프로젝트에 학습 경로 즉시 생성 | Project draft, 가설 확정/성장 없음 | 학습 홈 |
| 학습 홈 | 현재 프로젝트와 경로, 다음 학습 하나. 주요 CTA 이어서 배우기. 스탯 없음 | 조회만 | 세션 |
| 개념 | 상황 예시와 짧은 설명, 배울 이유, 캐릭터 | 세션 단계 | 문제 |
| 문제 | 정답+이유 선택, 즉시 피드백. 오답은 다른 문항, 소진 시 도움받아 응용 | 기존 개념 이해 XP 최대10, 반복 무보상 | 응용 연습 |
| 응용 연습 | 새 상황 판단. 이미 이해한 개념은 설명을 건너뛰어 여기서 시작 가능 | 기존 적용 평가 최초20, 오답/설명만으로 성장 없음 | 내 프로젝트 적용 |
| 내 프로젝트 적용 | 대상·개념별 결과물·확인 기준을 직접 작성하고 확정 | 프로젝트/가설 범위별 학습 산출물. 자유서술은 자동 숙달 채점 안 함. 현장검증 스탯 없음 | 학습 완료 |
| 학습 완료 | 완료 연출, 남은 산출물 강조. 보조로 학습 보상. 실행 과제 한 개 제안 | 학습 완료와 현장 실행 완료 분리 | 실행 계획 또는 홈 |
| 실행 | 진행 과제 하나, 결과 기록/보류. 새 과제 선택 시 기존 것은 명시적으로 교체 | 과제 상태. 결과는 기존 근거 확인 화면으로 연결, 확정 전 성장 없음 | 근거 확인→홈 |
| 프로젝트 상세 | 기존 Context/관찰/결정/7축 확인 | 기존 규칙 | 홈 |
| 나의 성장 | 본캐 이해/적용 이력, 선택 복습 | 기존 규칙 | 홈 또는 세션 |

세션은 concept → question → transfer → apply → complete로 저장한다. UI에는 개념/문제/응용 세 단계로 표시한다. 한 화면 primary CTA는 하나를 기본으로 하며 돌아가기/나중에/이미 알아요는 보조 표현한다. 메뉴는 학습 길·내 프로젝트·나의 성장, 설정은 헤더. 부캐는 홈에서 학습 동반자로 등장한다.

## 추천·실행·데이터

- 프로토타입 기본 경로: 고객→제품→시장→고객 확보→재무→운영→전략. 고객 근거가 반박되면 아직 안 한 전략 학습을 앞당긴다. 완료한 학습은 복습 가능. 이 결정형 규칙을 실제 AI 개인화라고 표현하지 않는다.
- 새 프로젝트는 Context null 상태로 시작한다. 적용 산출물을 사용자가 확정할 때 대상과 확인 방법을 기존 Context와 병합하되, 기존 확정 고객을 임의 변경하지 않는다. 결과물은 가설/준비물이지 관찰이 아니다.
- 학습 진행은 프로젝트+scopeVersion+concept, 숙달/XP는 사용자+concept 기준이다. 프로젝트 전환 시 산출물/진도는 별도, 기존 지식은 재사용한다.
- 외부 실행은 학습 완료 조건이 아니다. 진행 중 실행 과제는 하나만 유지하며 새 산출물은 보관한다. 다음 학습을 막지 않는다. 교체 시 이전 과제는 보류 이력으로 보존한다.
- 결과 기록은 학습 산출물의 개념/가설과 연결한다. source/date/method/observation/interpretation/limits를 보존한다. 전략 학습의 실행 결과는 Decision으로 이어지며 관찰만으로 전략 보상하지 않는다.
- schemaVersion1에 선택 필드 learningRuns/learningArtifacts/fieldTasks를 추가하며 기존 프로젝트·이벤트·XP·draft를 삭제하지 않는다. 기존 세션은 기존 화면에서 재개할 수 있지만 홈은 새 학습 길로 진입한다.
- 생명 소모/리더보드/실패 벌점/매일 외부 실행 강제 없음. 기존 모션 감소, 로컬 오류 처리 유지.

## 수용 기준

| AC | 검증 |
|---|---|
| AC-L01 | 새 프로젝트는 6문답 없이 학습 홈. 홈에는 스탯/7개 학습 선택 카드 없음 |
| AC-L02 | 개념→문제→새 상황→내 프로젝트 산출물→완료→실행을 하나의 안내 흐름으로 조작 |
| AC-L03 | 세션/입력/reload 복원, 기존 저장자료 보존, 중복 XP/완료 이벤트 방지 |
| AC-L04 | 오답 소진 시 학습이 막히지 않으며 설명 읽기만으로 숙달 지급 없음 |
| AC-L05 | 학습 완료≠현장검증, 진행 실행1개, 교체 명시, 외부 실행 대기 중 다음 학습 가능 |
| AC-L06 | 7개 개념별 산출물/실행 안내, 상세 스탯 접근, 모바일/모션 감소 |
