# SPEC-012 — 집중형 상호작용·다이얼로그

Revision 0.1 · AUTH-016 · 2026-09-26
사용자 승인: 공통 정책 명세 후 기존 코드 개선, 답/이유 문제 풀이 개선 반드시 포함.

## 공통 정책
- 한 화면에는 현재 판단 하나. 힌트(요청형), 채점 결과(명시적 제출 후), 중요한 확인에 modal을 사용한다. 일반 저장 완료·선택 반응·주 콘텐츠는 modal로 바꾸지 않는다.
- 모바일 ≤600px: 아래쪽 modal sheet, 넓은 화면: 중앙 dialog. 같은 내용·동작을 유지하며 드래그로 닫기는 이번 범위 제외.
- 제목→핵심 설명→주 행동 하나. 결과와 XP를 한 창에 통합한다. 중첩 금지. 긴 내용은 내부 스크롤, 최대 높이 85dvh, safe-area 여백, 44px 이상 조작 영역.
- 힌트·학습 결과는 닫기/Escape 허용, 배경 클릭은 닫지 않음. 닫으면 선택과 위치 유지. 결과는 다시 보기 가능. 중요한 확인의 닫기/취소는 동의가 아니며 실행하지 않는다.
- native dialog showModal: 배경 비활성, 포커스 내부 제한, 제목 연결, 열 때 제목에 포커스, 닫으면 호출 버튼 또는 재생성된 대응 버튼으로 복귀. body 스크롤 잠금.
- 모션은 SPEC-008 계승: 180ms 아래→위 fade, reduced-motion은 이동·애니메이션 없음. 기존 색상·버튼 눌림 유지.

## 첫 적용 — 오늘의 학습
question 및 transfer에 동일 적용. 탭처럼 보이는 2단계 표시를 사용하되 자유 탭 선택 대신 순차 흐름(aria-current=step).
1. 답 고르기: 문제·답 선택지 하나만. 선택 후 다음(명시적 제출). 이유는 아직 숨김.
2. 이유 고르기: 선택 답 요약·이유 선택지만. 답 바꾸기로 복귀, 선택 모두 유지. 답 확인하기로 채점.
3. 채점 결과 dialog: 답/이유 각각의 정오답, 해설, 기존 XP 결과. 주 행동은 기존 분기에 따른 다른 문제/새 상황/내 프로젝트 응용. 닫으면 해설 다시 보기 제공.
- 선택·하위 단계는 Project.uiDraft[question:scopeVersion:concept:step:variant]에 저장. 페이지 재로드/프로젝트 전환 시 복원. 다른 문제·가설 범위와 혼합 금지. 기존 저장은 필드 없으면 답 단계로 시작.
- 저장 실패 시 단계 이동/결과 dialog/추가 보상 없음. 결과 재열람은 채점·이벤트를 재실행하지 않는다. 기존 점수·재시도·학습 경로는 SPEC-002/005 유지.
- 힌트는 native details 대신 버튼으로 요청, dialog에서 설명. 이유 선택 전 정오답을 노출하지 않는다.

## 적용 경계 및 AC
공통 dialog 유틸리티와 오늘의 학습 question/transfer에 적용. 기존 독립 복습 quiz/근거 확인/reward의 전면 교체는 후속 검토. 외부 배포는 이번 요청 범위 아님.
AC-D01 답/이유 동시 노출 없음, 뒤로/새로고침 복원.
AC-D02 힌트/결과 modal, 닫기/재열람/중복 XP 없음.
AC-D03 정답/오답/재시도/transfer/저장 실패 기존 규칙 유지.
AC-D04 모바일 sheet/desktop 중앙, 키보드 포커스·Escape·긴 내용·모션 감소.
자동검사와 브라우저 검증은 VAL-010에 기록. 실제 사용자 연구·물리 모바일 검증은 별도.
