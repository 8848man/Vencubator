# SPEC-008 — 프로토타입 모션·로딩 규칙

Revision 0.1 · S1 구현 승인 AUTH-008 · 2026-09-24

사용자: “좋아. 이제부터 명세 + 프로토타입에 적용 부탁해”. 직전 제안(위→아래 순서, 아래→위 페이드인, 눌림, 실제 비동기 스켈레톤)을 구체화한다. 기존 색·레이아웃·성장 정책은 유지한다. 적용 범위는 prototype/이며 랜딩 두 버전은 제외한다.

## 공통 토큰과 동작

| 대상 | 규칙 | 발생 시점 |
|---|---|---|
| 화면 진입 | opacity 0→1, translateY 10px→0, 260ms ease-out | 최초 진입, 화면·프로젝트·학습 단계·문항 변경 |
| 순차 등장 | 의미 단위 그룹을 화면상의 위→아래, 같은 높이는 왼쪽→오른쪽. 50ms 간격, 지연 최대200ms(전체460ms) | 헤더·카드·폼·학습 경로 묶음. 부모와 자식 중복 금지 |
| 입력·동일 화면 갱신 | 기존 그룹 재등장 없음 | 답안 선택, 자동 저장, 설정 변경, 스탯 펼치기 |
| 피드백 | 새로 생긴 정오답 결과/보상만 180ms, 위로6px | 결과를 처음 표시할 때. 같은 결과 재렌더 제외 |
| 터치·마우스·키보드 | 누를 때 scale .98 + 아래2px, 그림자 축소. 80ms 진입/140ms 복귀 | 버튼·클릭 카드·답안 선택지·summary. 실행 시점은 기존 click/submit 유지 |
| 취소 | pointerup/cancel/leave, keyup/blur에 즉시 눌림 해제 | 스크롤로 취소돼도 눌림이 남지 않음. disabled는 반응 없음 |
| 선택 상태 | 손을 떼면 크기 복귀, 선택 테두리·색 유지 | radio/checkbox 선택. 상태 의미를 모션에만 의존하지 않음 |
| 스켈레톤 | 실제 응답 대기 영역만 회색 형태로 대체. 텍스트 줄/제목 공간 예약 | 인터뷰 질문 대역. 입력 폼·작성값은 유지, 완료까지 강제 지연 없음 |

화면 아래 그룹은 최초 진입 순서에 포함하되 보이게 하려고 자동 스크롤하거나 별도 지연하지 않는다. 글로벌 내비게이션·입력 필드·문항 개별 선택지를 차례로 숨기지 않는다. 효과 종료를 기다려 클릭/키보드 입력을 막지 않는다. 진입 transform과 눌림 scale/translate는 서로 덮어쓰지 않는다.

## 비동기·오류·접근성

- 인터뷰 요청 식별자는 프로젝트+문항+대역 모드. 같은 요청의 재렌더는 재요청하지 않고 진행 상태를 재사용한다. 늦게 도착한 이전 요청은 현 화면에 반영하지 않는다.
- 질문 영역에 aria-busy, 별도 role=status 안내. 장식 스켈레톤은 aria-hidden. 성공은 질문을 표시하고, 실패는 메시지와 준비된 기본 질문을 표시한다. 폼과 초안은 그대로 둔다.
- 동기 로컬 저장과 즉시 제공 가능한 학습 콘텐츠에 가짜 로딩을 추가하지 않는다. 기존 저장 실패 안내를 유지한다.
- OS prefers-reduced-motion 또는 앱 ‘움직임 줄이기’ 중 하나라도 켜져 있으면 진입/눌림 이동·확대축소·반복 shimmer를 끈다. 정적인 스켈레톤·색상/테두리 피드백·완료 문구는 유지한다.
- 키보드 focus-visible을 보존한다. 화면 전환의 제목 포커스 및 학습 결과 포커스는 기존 규칙을 유지한다.

## 수용 기준

- AC-M01: 홈/세션/일반 폼에서 의미 그룹이 위→아래 순서로 아래→위 페이드인. 최대 지연200ms, 총460ms.
- AC-M02: 답안 선택·입력 저장·같은 화면 갱신은 전체 진입을 재실행하지 않음. 다른 문항/학습 단계에서는 실행.
- AC-M03: 포인터/키보드 누름, 해제/취소/창 이탈 복귀. disabled 제외. 선택 상태 유지.
- AC-M04: 정상/지연/실패 질문 대역에서 스켈레톤→본문 또는 오류+기본질문. 입력·이탈 보호.
- AC-M05: 앱/OS 모션 감소 시 이동·shimmer 없음. 모바일 가로 넘침 없음.
