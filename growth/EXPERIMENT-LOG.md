# 실험 기록

매주 금요일에 한 블록씩 추가한다. 기존 블록은 고치지 않고, 정정은 새 블록에 적는다. 수치는 항상 **분자/분모**로 적는다.

## 현재 상태

| 항목 | 값 |
|---|---|
| 라운드 | R1 (계획됨, 미시작) |
| 실행 승인 | 없음 — DR-G01~G06 결정 대기 |
| 배포 | 없음 (로컬 전용) |
| 수집 데이터 | 없음 |

---
