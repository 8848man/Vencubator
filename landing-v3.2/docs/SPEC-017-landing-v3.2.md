# SPEC-017 — Vencubator 랜딩 v3.2 “평이한 첫 화면”

Revision 0.1 · AUTH-028 · 2026-09-30 · 기반 SPEC-016 r0.1(v3.1) · 정책 [POLICY](POLICY.md) · 작업 [WORKORDER](WORKORDER.md)

v3.1(SPEC-016)을 복사한 `landing-v3.2/`의 계약이다. **메시지 개정만 한다.** v3.1과 같은 부분은 그대로 두고, ★로 표시한 행·절만 바꾼다. SPEC-016과 `landing-v3.1/`은 수정하지 않는다(POLICY PM-1).

## 1. 범위

| 포함 | 제외 |
|---|---|
| ★첫 화면 카피 위계(대상·가치·결과물), ★가치 3줄(`gets`), ★층·하베스트·버튼 문구를 평이한 말 우선으로, ★후보 미리보기 `?h=`, 식별자 v32 | 상호작용·상태 모델·모션 변경, 새 이벤트, 퀴즈·7영역·예시·관찰 답·고민 선택 변경, 서버 전송, 실제 AI, A/B 배정 |

|---|---|---|
| `SITE.variant` | `v31` | `v32` |

`index.html` head의 Google Search Console 확인 메타는 그대로 둔다.

## 3. 섹션 계약

섹션 ID·순서·type은 SPEC-016 §3과 같다. 차이:

| ID | ★변경 |
|---|---|
| L3S-01 `surface` | `hook` 삭제(MP-5). 순서: eyebrow(대상) + badge → h1(핵심 가치) → lead(결과물) → ★`gets` 3줄 → 입력(이름표 모양 그림은 유지) → 예시 칩 → 앱 보조 링크 → 개인정보 문구 |
| L3S-03~07 층 | `title`을 평이한 말로. 은유 라벨(`stratum · depth`)은 제목 **앞** 작은 보조 라벨로 유지 |
| L3S-08 `aboveBelow` | 제목·태그에서 부캐·본캐 제거 |
| L3S-09 `honest` | S3 이름에서 ‘코파일럿’ 제거 |
| L3S-10 `harvest` | 제목·버튼을 평이한 말로 |

### 3.1 ★가치 3줄 `gets`

- 마크업: `<ol class="l3-gets" aria-label="이 페이지에서 해 보는 것">`, 항목 3개, 각 `<strong>`(t) + `<span>`(d). **테두리 없음**(조작 요소가 아님 — v3 시각 규칙). 링크 아님(새 상호작용 없음).
- 항목 앞에는 번호 대신 해당 층 색 점(●). 챕터 번호 `n/N` 금지 규칙(AC-L3-05) 유지.
- 좁은 화면(≤ 480px): `d` 숨김, `t`만 한 줄씩.

## 7. 카피 (★)

### 7.1 첫 화면 후보 `HEADLINES` (기본값 `SITE.headline = 'a'`)

공통 eyebrow: **“사이드 프로젝트·1인 창업을 준비하는 메이커를 위해”**

| 키 | h1 (두 줄) | lead |
|---|---|---|
| **a** (기본, 문제 중심) | 만들기 전에, / 쓸 사람이 있는지부터. | 아이디어 한 문장이면 몇 분 안에, 오늘 확인할 개념 하나와 고객에게 물어볼 질문 3개, 들은 답으로 다음 방향을 정하는 법까지 한 바퀴 돌아봐요. |
| b (대상 중심) | 사이드 프로젝트, / 만들기 전에 확인하는 법. | 개발·디자인은 할 줄 아는데 고객 검증은 처음이라면. 아이디어 한 문장으로 무엇을, 누구에게, 어떻게 물을지 몇 분이면 정리돼요. |
| c (결과 중심) | 아이디어 한 문장으로, / 이번 주에 할 일 하나. | 무엇부터 확인할지, 누구에게 무엇을 물을지, 들은 답으로 무엇을 정할지까지. 만들기 전에 필요한 첫 한 바퀴를 돌아봐요. |

참고(코드에 넣지 않음) — C′ 학습형: “창업 공부, / 내 아이디어로 바로 해 봐요.” POLICY DR-LM-01을 “학습”으로 바꿀 때만 후보로 추가.

5초 테스트 결과로 기본값을 바꾸면 이 표의 “기본” 표시와 `SITE.headline`만 바꾼다.
