# Vencubator 프로토타입

실행: 프로젝트 루트에서 `node prototype/server.mjs`, 브라우저 `http://127.0.0.1:4183`.

테스트: `node --test prototype/tests/*.test.mjs`.

외부 라이브러리 설치·API key가 필요 없습니다. 실제 로그인·AI·알림이 아닌 가상 데이터 체험입니다. 저장은 이 브라우저의 `vencubator.prototype.v1` 영역만 사용합니다. 데모 사용자 이름 외에 실제 고객 개인정보를 입력하지 마세요.

화면: 데모 시작, 한 문장 프로젝트 생성, 학습 길, 개념·문제·응용·학습 완료, 실행 과제·회고, 프로젝트 상세, 나의 성장. 기존 인터뷰/근거 기록은 상세 기능으로 유지합니다. 설정에서 오류/지연·저장 실패와 모션 감소를 재현할 수 있습니다.

기술 결정: docs/adr/ADR-003-prototype-runtime.md. 서버는 loopback에서 prototype 디렉터리만 제공합니다. 기존 output/기획 문서/비밀 파일은 제공하지 않습니다.

## 5분 체험

1. 이름을 적고 프로젝트를 한 문장으로 만듭니다. 기존 TeamUp 샘플도 새 학습 길을 사용합니다.
2. 홈의 “오늘의 학습 시작”을 누르면 개념→문제→새 상황 적용을 안내합니다.
3. 내 프로젝트의 대상·준비물·판단 기준을 직접 작성해 확정합니다. 학습은 여기서 완료됩니다.
4. 준비물로 실행 과제를 선택합니다. 실행 대기 중에도 다음 학습을 할 수 있습니다.
5. 가상 실행 결과를 기록하고 확인합니다. 전체 스탯은 “내 프로젝트 자세히 보기”에서 확인합니다.

저장 실패를 켰다면 화면의 ‘저장 실패 해제’ 후 동일 내용을 다시 저장하세요. 실패 중 새로고침은 미저장 입력을 잃을 수 있습니다. 삭제/초기화 전에 JSON 백업이 가능합니다. 백업 import는 아직 제공하지 않습니다.

## 작업 이어가기

`node scripts/verify-checkpoint.mjs` → STATE의 next W → 관련 Spec/Stage/VAL-003 순서로 읽습니다. 검사 결과 Changed since checkpoint는 자동 삭제 신호가 아니라 해당 파일 대조가 필요하다는 뜻입니다. 진행 상태는 대화 기억 대신 STATE와 CP에 저장합니다.
# 공통 모션

SPEC-008 r0.1: 화면·학습 단계 전환에서 위→아래 순차, 아래→위 페이드인(260ms/50ms 간격/최대 지연200ms). 버튼·선택지의 눌림과 실제 질문 대기 스켈레톤을 지원한다. 설정 ‘움직임 줄이기’ 및 OS 모션 감소를 반영한다. 학습/로컬 저장에 가짜 로딩은 없다. 검증은 docs/validation/VAL-005-motion.md.

## 같은 사이트에서 실행 (SPEC-009)

`node site/scripts/build.mjs && node site/scripts/serve.mjs` → http://127.0.0.1:4180/ 에서 랜딩(/v1/ 또는 /v2/)을 거쳐 `/app/`으로 들어온다. 파일은 상대 경로로 부른다. `?from=v2`로 열리면 랜딩 v2의 아이디어 문장만 새 프로젝트 입력칸에 채운다(`entry.mjs`). 이벤트는 `track.mjs`로 브라우저 버퍼에만 기록한다.

## 점검 도구

설정 화면의 AI 응답 지연·실패 재현, 저장 실패 재현은 주소에 `?lab=1`이 있을 때만 보인다. 일반 사용자 화면에는 노출하지 않는다(SPEC-009 r0.3).
