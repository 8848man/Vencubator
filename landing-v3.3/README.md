# 랜딩 v3.3

모바일 첫 시작 흐름을 소개하고 핵심 선택을 미리 눌러볼 수 있는 독립 페이지다. `/v3.3/` 직접 URL은 모바일에서도 랜딩에 남는다. 답변은 이 페이지 밖으로 저장하거나 앱에 인계하지 않는다. 실제 앱 시작 버튼은 `/app/`으로 이동한다.

실행: 프로젝트 루트에서 `node site/scripts/build.mjs` → `node site/scripts/serve.mjs` → `http://127.0.0.1:4180/v3.3/`.

작업 기준: [SPEC-019](../docs/specs/SPEC-019-mobile-entry.md). 현재 산출물은 로컬 프로토타입이며 운영 배포는 하지 않았다.
