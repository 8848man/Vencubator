# 랜딩 v3.3 및 마이루틴 레퍼런스 흐름

`/v3.3/`은 정보 입력을 브라우저에 저장하는 짧은 첫 사용 흐름이다. 화면 폭과 관계없이 1~4구간을 진행하고, 5구간은 실제 `/app/`의 첫 프로젝트 화면에서 한 조작 대상씩 강조한다. 사이트 `/`의 600px 이하 앱 직접 진입은 유지한다. 기존 입문 랜딩은 `/beginner/`에서 볼 수 있다.

`/v3.3/reference/`는 제공된 마이루틴 스크린샷 54장의 **흐름과 화면 역할**을 벤큐베이터의 언어로 번안한 UX 연구용 시뮬레이션이다. 원본 화면·이미지는 배포물에 복사하지 않으며, 선택 답변은 메모리에만 유지된다. 실제 인증·서버 저장은 아직 연결되지 않았다.

실행: 프로젝트 루트에서 `node site/scripts/build.mjs` → `node site/scripts/serve.mjs 4080` → `http://127.0.0.1:4080/v3.3/` 또는 `http://127.0.0.1:4080/v3.3/reference/`. 다른 포트에서도 같은 경로다. 이미 서버를 켰다면 재빌드 후 새로고침한다.

작업 기준: [SPEC-019](../docs/specs/SPEC-019-mobile-entry.md). 현재 산출물은 로컬 프로토타입이며 운영 배포는 하지 않았다.
