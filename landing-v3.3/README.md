# 랜딩 v3.3 및 마이루틴 레퍼런스 흐름

`/v3.3/`은 별도 디자인이 아니라 기존 사이트의 v3.1 입문 랜딩과 독자 선택 흐름을 그대로 사용한다. 이 URL과 사이트 `/`은 600px 이하에서 바로 `/app/`으로 이동한다.

`/v3.3/reference/`는 제공된 마이루틴 스크린샷 54장의 **흐름과 화면 역할**을 벤큐베이터의 언어로 번안한 UX 연구용 시뮬레이션이다. 아이디어·학습·고객 확인 소개 → 질문 → 요약 → 첫 프로젝트 실습을 화면별로 조작한다. 원본 화면·이미지는 배포물에 복사하지 않으며, 선택 답변은 메모리에만 유지된다.

실행: 프로젝트 루트에서 `node site/scripts/build.mjs` → `node site/scripts/serve.mjs 4080` → `http://127.0.0.1:4080/v3.3/` 또는 `http://127.0.0.1:4080/v3.3/reference/`. 다른 포트에서도 같은 경로다. 이미 서버를 켰다면 재빌드 후 새로고침한다.

작업 기준: [SPEC-019](../docs/specs/SPEC-019-mobile-entry.md). 현재 산출물은 로컬 프로토타입이며 운영 배포는 하지 않았다.
