# SPEC-010 — Vencubator 랜딩 v3 “뿌리”

Revision 0.2 · Implemented (L04-W02) · 공개 랜딩 확정 · 2026-09-26

r0.2 변경: 사용자 결정으로 v3를 사이트 유일 랜딩(`/`)으로 고정. 사용자에게 필요 없는 정보(명세·기획서 링크, 내부 단계 코드, 개발 용어, 소스 주석)를 공개 화면·공개 빌드에서 제거하고, 진행 상황 섹션을 “지금·다음·그다음” 로드맵으로 다시 썼다(§3 L3S-09, §8).

사용자 요청: “재구성해서 v3 프로토타입을 만들 수 있나? 너무 배낀 티가 안나게끔”. 근거 [PRINCIPLES](PRINCIPLES.md)(DP-1~12), 사이트 계약 [SPEC-009](../../docs/specs/SPEC-009-site.md), 검증 [VAL-L03](VAL-L03.md). v1(SPEC-006)·v2(SPEC-007)는 수정하지 않는다.

## 1. 범위

| 포함 | 제외 |
|---|---|
| 정적 단일 페이지, 이름표 입력 → 지층 4개 체험(퀴즈·질문·관찰 해석·결정) → 뿌리 지도 → 위와 아래(부캐/본캐) → 앞으로 자랄 모습 → 앱에서 심기. 스크롤에 따라 그려지는 뿌리, 깊이 눈금, 반응형, 모션 감소, 로컬 저장, 단일 파일 빌드, 공개 빌드(사이트 루트) | 서버 전송, 실제 AI, 호스팅 계정·도메인 설정(사용자 수행), A/B 순환(r0.2에서 종료) |

## 2. 파일 계약

v2와 같은 구조: `src/content.mjs`(카피) · `src/state.mjs`(순수 상태, v2 모델 계승) · `src/render.mjs`(순수 렌더) · `src/interact.mjs`(이벤트·뿌리·깊이) · `src/track.mjs`(site/shared 복사본) · `src/tokens.css` · `src/landing.css` · `scripts/build.mjs`(opts.public, opts.outFile) · `scripts/serve.mjs`(4176, `/app/` 연결) · `scripts/qa.mjs` · `start.cmd`.

## 4. 상태 모델

v2 `state.mjs`와 같은 액션·파생 규칙을 쓴다(SPEC-007 §4). 차이: 저장 키 `vencubator.landing.v3`, 칸 이름(이름표·배운 것·질문·들은 답·결정), `deriveCard.status`의 `example` 값은 **다 쓴 예시 기록 문장**(빈 안내문 아님). `rootState(state)` 추가: 층별 `mine|example`, 반박 여부.

## 6. 모션

| ID | 대상 | 규칙 |
|---|---|---|
| L3M-01 | 뿌리 줄기 | 흙 구간 진행률 p = (scrollY + 0.6vh − 흙 시작) / 흙 높이. `stroke-dashoffset = 길이 × (1−p)`. rAF 1회 스로틀. 고정 없음 |
| L3M-02 | 깊이 눈금 | 층 경계(0·15·40·70·100cm) 눈금과, 뿌리 끝을 따라다니는 현재 깊이·지층 이름(층 경계 사이 선형 보간). 좁은 화면에서는 깊이 숫자만 |
| L3M-03 | 층 뿌리 | 내가 채운 층의 곁뿌리는 연두 실선으로 그려짐(600ms), 예시 층은 점선 |
| L3M-04 | 우회 뿌리 | 반박 시 관찰 층 기록 높이에서 줄기가 옆으로 꺾이고(폭 `--rail-turn`, 좁은 화면에서 줄임), 원래 방향으로 조금 뻗다 멈춘 막힌 뿌리가 주황 점선으로 남는다 |
| L3M-05 | 이름표 입력 | 비어 있고 포커스가 없을 때 예시 문장이 손글씨로 한 글자씩 써짐(순환). 입력·포커스 시 멈춤 |
| L3M-06 | 층 진입 | 첫 진입 시 글이 흙에서 떠오르듯 12px 상승 + 불투명 (초기 상태도 읽을 수 있는 불투명도 0.35 이상) |
| L3M-07 | 새싹 | 채운 층 수로 자람(v2 `--grow`) |

`prefers-reduced-motion`: 뿌리·눈금은 최종 상태, 타이핑·흔들림 없음, 진입 효과 없음.
