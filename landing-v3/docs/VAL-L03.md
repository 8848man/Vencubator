## 참고 사이트 겹침 점검 (PRINCIPLES §3)

자동 검사(AC-L3-05): sticky는 상단바만, `position: fixed` 없음, 100vh 초과 높이 없음, `0n/0n` 챕터 번호 없음, 섹션에 인덱스 숫자 필드 없음. 히어로 문장 확대, 문장 교차 무대, 숫자 브리지, 5프레임 무대, 하단 고정 CTA는 구현에 없다.

## 한계·미실행

- 클라우드에서는 폰트 CDN이 막혀 같은 글꼴의 npm 배포본으로 검토했다. 실제 CDN 로딩은 사용자 환경에서 확인 필요.
- Safari/Firefox, 실기기, 스크린리더 수동 검사 미실행. 뿌리·깊이 표시는 장식(aria-hidden)이며 같은 정보는 각 층 머리말 텍스트로 제공한다.
- “뿌리” 은유가 초보자에게 바로 읽히는지, v1·v2보다 나은지는 사용자 확인 전이다. A/B 비율은 0이며 `?v=v3`로만 열린다.
