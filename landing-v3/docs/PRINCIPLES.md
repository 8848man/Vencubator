# 랜딩 v3 설계 원리 — “뿌리”

기준일 2026-09-25 · 대상 `landing-v3/` · 계약 [SPEC-010](SPEC-010-landing-v3.md) · 이전 원리 [v2 PRINCIPLES](../../landing-v2/docs/PRINCIPLES.md)

## 0. v1·v2 회고

| | v1 | v2 |
|---|---|---|
| 좋았던 것 | 밝음/어둠 대비, 화면을 채우는 규모, 스크롤만 해도 보이는 변화, 가만히 있어도 완성된 인상 | 내 아이디어로 직접 해보기, 앱으로 문장 인계, 예시와 내 것의 정직한 구분 |
| 문제 | 참고 사이트의 섹션 순서·장치(문장 교차 무대, 숫자 브리지, 5프레임 무대, 하단 바)를 그대로 따름 | 기능적 원리만 남기고 **감정적 원리**(대비·규모·리듬·스크롤의 즐거움)를 버림. 조작 전 화면이 “비어 있음”으로 보여 미완성처럼 느껴짐. 모든 블록이 카드 |

v2 원리 DP-1~8은 유지한다. 단 DP-8(“모션은 상태 변화에만”)은 **과했다**고 보고 아래 DP-9~12로 보완한다.

## 1. 추가한 원리

| ID | 원리 | v1에서 확인한 효과 | v3에서 지킬 조건 |
|---|---|---|---|
| DP-9 | **대비가 장(章)을 만든다.** 밝기·밀도·규모가 바뀌는 순간이 새 장의 시작 | 밝은 구간 → 숲색 구간의 전환이 기억에 남음 | 대비의 이유가 제품 의미에서 나와야 한다(장식용 어둠 금지) |
| DP-10 | **장마다 기억될 장면 하나.** 한 장에 가장 큰 것 하나 | 화면을 채우는 문장·숫자 | 거대한 숫자·문장 교차 같은 참고 사이트 장치는 쓰지 않는다 |
| DP-11 | **스크롤은 이야기의 시간이다. 단, 붙잡지 않는다.** 스크롤에 따라 계속 변하는 것이 있어야 하지만, 화면 고정으로 스크롤을 빼앗지 않는다 | 스크롤할수록 새싹이 자람 | 고정(sticky) 무대 없음. 모션 감소 시 최종 상태 |
| DP-12 | **가만히 있어도 완성.** 조작하지 않은 방문자에게도 완성된 한 장면 | v1은 모든 섹션이 완성 상태로 보임 | 예시는 “비어 있음”이 아니라 **다 쓴 예시 기록**으로 보여 준다 |

## 2. 독립 표현 — 컨셉 “뿌리”

> 아이디어는 땅 위에서 자라는 새싹이고, 근거는 땅속에서 자라는 뿌리다. 페이지를 내려가는 것은 **땅속으로 들어가는 것**이다.

Vencubator의 제품 철학이 이 은유에 그대로 들어맞는다.

| 제품 원칙 | “뿌리”로 표현 |
|---|---|
| 한 문장이면 시작 | 첫 화면은 지상. 새싹 옆에 꽂는 **식물 이름표**가 곧 입력칸 |
| 오늘 배울 것 → 내 질문 → 들은 답 → 결정 | 땅속 **지층**. 깊이(cm)가 곧 진행 단계 |
| 반박도 성장 | 예상과 다른 답을 고르면 **뿌리가 방향을 튼다**. 막힌 쪽 뿌리도 기록으로 남는다 |
| 점수 대신 근거 | 뿌리는 보이지 않지만 식물을 지탱한다. 숫자 대신 “얼마나 깊이 내려갔는지” |
| 부캐(프로젝트)·본캐(학습) | **땅 위의 줄기와 잎 = 부캐**, **땅속 뿌리 = 본캐**. 새 프로젝트를 심어도 뿌리는 남는다 |
| 7개 영역 중 오늘 하나 | 가장 깊은 곳의 **일곱 갈래 뿌리 지도**. 지금 자라는 한 갈래만 밝다 |

원리별 표현:

| 원리 | v3 표현 |
|---|---|
| DP-9 대비 | 지상(밝은 온실) → 겉흙(모래빛) → 속흙(황토) → 깊은 흙(짙은 부엽토) → 다시 지상. **밝기가 깊이를 뜻한다** |
| DP-10 장면 하나 | 지상: 크게 꽂힌 이름표 / 겉흙: 개념 한 줄 / 속흙: 내 고객 이름 / 깊은 흙: 방향을 트는 뿌리 / 최하층: 일곱 갈래 뿌리 지도 / 지상 복귀: 자란 식물과 내 이름표 |
| DP-11 스크롤 | 왼쪽 가장자리를 따라 **뿌리 한 줄기가 스크롤만큼 그려진다**(고정 없음). 가장자리의 **깊이 눈금**이 0cm → 100cm로 움직인다 |
| DP-12 완성 | 기본 상태가 “다 쓴 예시 기록”(연필 글씨)이다. 내가 채운 층의 뿌리는 연두색 실선, 예시 층은 점선 |
| DP-3 위치=진척 | 챕터 번호 대신 **깊이(cm)와 지층 이름** |
| DP-5 전환 | 하단 바 대신 마지막 지상 장면의 이름표와 “앱에서 심기” |

## 3. 참고 사이트와 겹치지 않는지 점검

| 참고 사이트 장치 | v1 | v3 |
|---|---|---|
| 히어로 문장 축소/확대 + 미디어 확대 | 사용 | **없음**. 지평선과 이름표 |
| 고정 무대에서 문장 3개 교차 | 사용 | **없음** |
| 원칙 5칸 순차 등장 | 사용 | **없음**. 원칙은 지층 이야기 안에 녹임 |
| 4단계 연결 경로 카드 | 사용 | **없음**. 지층 자체가 순서 |
| 방법 그리드 | 7영역 그리드 | **뿌리 지도**(갈래 도형) |
| 21 → 05 숫자 브리지 | 7 → 1 | **없음** |
| 고정 무대 5프레임 + 거대 인덱스 숫자 | 사용 | **없음** |
| 일정 행 초점 | 사용 | **없음**. 진행 상황은 짧은 표 |
| 챕터 번호 `01/07` + 진행 막대 | 사용 | **깊이 눈금(cm)** |
| 하단 고정 CTA 바 | 사용 | **없음** |
| smoothstep 스크롤 계산 | 사용 | 뿌리 그리기에 선형 진행만 |

## 4. 시각 언어

- **색**: 지상 `#f2f6ec`(온실 빛) · 겉흙 `#e9dfcb` · 속흙 `#cdb690` · 깊은 흙 `#4a3b2d` · 부엽토 `#241d16` · 뿌리 연두 `#b9da8c` · 새싹 녹색 `#2e5e47` · 반박 주황 `#d08a4a`. 흙은 제품 녹색과 짝이 되도록 따뜻한 갈색 계열.
- **글꼴**: 제목 Hahmlet(한국어 세리프, 굵기 폭이 넓음) · 본문 Pretendard · 이름표와 예시 기록 Nanum Pen Script(손글씨, 짧은 곳에만) · 깊이 눈금 IBM Plex Mono.
- **형태**: 카드 남용 금지. 테두리 있는 판은 **조작할 수 있는 것**에만(퀴즈·입력·선택). 나머지는 흙 위에 바로 놓인 글.

## 5. 미확정

- 은유가 초보자에게 바로 읽히는지는 사용자 확인이 필요하다. 지층 이름 옆에 실제 뜻(“오늘 배울 것” 등)을 항상 함께 쓴다.
- v3를 A/B 순환에 넣을지는 사용자 결정. 기본 비율 0, `?v=v3`로만 연다.
